# Introduction

This repository contains many data structures supporting range updates and/or queries.

## Usage

Add this to your `Cargo.toml`:

```toml
[dependencies]
segtree = { git = "https://github.com/qdot3/segtree", version = "0.2.1" }
segtree_dual = { git = "https://github.com/qdot3/segtree", version = "0.2.0" }
segtree_lazy = { git = "https://github.com/qdot3/segtree", version = "0.1.1" }
bit = { git = "https://github.com/qdot3/segtree", version = "0.1.1" }
sparse_table = { git = "https://github.com/qdot3/segtree", version = "0.1.2" }
foldable_queue = { git = "https://github.com/qdot3/segtree", version = "0.2.1" }
foldable_deque = { git = "https://github.com/qdot3/segtree", version = "0.2.1" }

segtree_traits = { git = "https://github.com/qdot3/segtree", package = "traits", version = "0.1.3" }

op_add = { git = "https://github.com/qdot3/segtree", version = "0.1.1" }
op_min = { git = "https://github.com/qdot3/segtree", version = "0.1.2" }
op_max = { git = "https://github.com/qdot3/segtree", version = "0.1.2" }
op_affine = { git = "https://github.com/qdot3/segtree", version = "0.1.0" }
op_bitand = { git = "https://github.com/qdot3/segtree", version = "0.1.0" }
op_bitxor = { git = "https://github.com/qdot3/segtree", version = "0.1.0" }
op_bitor = { git = "https://github.com/qdot3/segtree", version = "0.1.0" }
```
